# NVIDIA Inception Program — Application Guide for TSAR

## What is NVIDIA Inception?

[NVIDIA Inception](https://www.nvidia.com/en-us/startups/) is a free program designed to help startups accelerate with NVIDIA technology. It provides:

- **Free cloud credits** for GPU compute
- **Technical support** and architecture reviews
- **Co-marketing** opportunities
- **Early access** to new hardware and software
- **Networking** with NVIDIA's partner ecosystem

## Why TSAR Should Apply

TSAR is an AI-powered trading system that uses LLMs for market analysis. NVIDIA Inception benefits directly map to TSAR's needs:

| TSAR Need | Inception Benefit |
|---|---|
| Run models on NVIDIA GPUs | Free cloud credits (AWS, GCP, Azure with NVIDIA GPUs) |
| Optimize inference latency | Technical support from NVIDIA engineers |
| Evaluate new models (Nemotron, etc.) | Early access to model releases |
| Scale from local to cloud | Architecture review sessions |
| Edge inference on Jetson | Hardware discounts and support |

## Eligibility Requirements

- **Startup stage:** Early-stage to Series A (seed-funded qualifies)
- **AI/ML focus:** Must be building an AI-powered product or service
- **NVIDIA technology:** Must use or plan to use NVIDIA GPUs/software
- **Not a consulting firm:** Must be building a product, not just services

> TSAR qualifies as an AI-powered fintech product using NVIDIA NIM, TensorRT-LLM, and GPU inference.

## Application Process

### Step 1: Prepare Your Application

Gather the following:

1. **Company overview** — What TSAR does (AI-powered crypto trading intelligence)
2. **Technical stack** — NVIDIA technologies used:
   - NVIDIA NIM API (DeepSeek R1, Nemotron models)
   - TensorRT-LLM (planned for local inference)
   - CUDA (for GPU-accelerated data processing)
3. **Traction/MVP** — Screenshots, demo, or description of working system
4. **Team info** — Founders and technical team
5. **Funding stage** — Bootstrapped / seed / Series A

### Step 2: Submit Application

1. Go to [https://www.nvidia.com/en-us/startups/](https://www.nvidia.com/en-us/startups/)
2. Click **"Join Inception"**
3. Fill out the application form
4. Select **"Financial Services / Fintech"** as industry vertical
5. Select **"AI Inference"** and **"LLM"** as primary use cases

### Step 3: Follow Up

- Applications are typically reviewed within **2-4 weeks**
- You may be contacted for a brief technical interview
- Highlight TSAR's use of NIM API and open-weights models (shows NVIDIA ecosystem commitment)

## Benefits Breakdown

### Cloud Credits

| Provider | Typical Credit | Notes |
|---|---|---|
| AWS | $5,000 - $50,000 | GPU instances (p4d, g5, etc.) |
| Google Cloud | $5,000 - $20,000 | A100/H100 instances |
| Azure | $5,000 - $25,000 | NC/ND series VMs |
| CoreWeave | Varies | GPU-native cloud |

*Credit amounts depend on stage and use case. Early-stage startups typically receive $5K-$15K total.*

### Technical Support

- **Architecture reviews** — NVIDIA engineers review your GPU workloads
- **Priority support** — Faster response on NIM / TensorRT issues
- **Training credits** — Access to NVIDIA Deep Learning Institute courses

### Software Access

- **NVIDIA AI Enterprise** — Free license for Inception members
- **Early model access** — New Nemotron, Llama, etc. before public release
- **TensorRT-LLM priority** — Early builds and optimization guides

### Marketing

- **NVIDIA blog features** — Case studies and joint announcements
- **GTC speaking slots** — Present at NVIDIA's GPU Technology Conference
- **Partner directory listing** — Visibility to NVIDIA's enterprise customers
